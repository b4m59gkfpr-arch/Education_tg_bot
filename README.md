# StudyBot AI (Multi-Tenant & PDF Support)

Обновленная версия проекта с интеграцией ИИ через **Groq API**, поддержкой загрузки **PDF-файлов** с выбором диапазона страниц, безопасной **авторизацией преподавателей** с подтверждением по почте (SMTP) и полной **изоляцией студентов и контента по учебным группам**.

---

## 🌟 Основные возможности

### 👨‍🏫 Панель преподавателя (Flask-админка)
* **Регистрация и Безопасность**:
  * Проверка сложности пароля (минимум 8 символов, заглавная/строчная буквы, цифра и спецсимвол).
  * Подтверждение регистрации по электронной почте (отправка 6-значного кода через SMTP-клиент).
  * Сессионная защита панели (вход по паролю).
* **Управление группами**:
  * Создание и удаление учебных групп (например, `2509`, `2510`).
  * Выбор активной группы для раздельного управления контентом.
  * Просмотр списка студентов, зашедших в активную группу (ФИО, Telegram Username, дата входа).
* **Ссылки-приглашения (Deep Linking)**:
  * Автоматическое определение юзернейма бота через запрос к Telegram API (`getMe`) по токену `BOT_TOKEN`.
  * Генерация персональных ссылок для каждой группы и кнопка быстрого копирования ссылки в буфер обмена на странице «Группы».
* **Генерация тестов и конспектов через ИИ**:
  * Использование API от **Groq** (модель по умолчанию: `llama-3.3-70b-versatile`).
  * Генерация на основе загруженных файлов `.txt`, `.md` или `.pdf`.
  * **Выборочное чтение PDF**: возможность указать начальную и конечную страницы для анализа (например, прочитать только страницы 5–15 из 100-страничного файла).
  * Защита ИИ от обработки «мусорных» страниц (автоматическое отсеивание титульных листов, оглавлений, аннотаций и списков литературы).

### 🎓 Telegram-бот для студентов
* **Умный онбординг**:
  * При первом входе бот просит студента выбрать группу из списка существующих в базе.
  * После выбора группы бот просит ввести ФИО для отображения в админке преподавателя.
* **Вход по ссылкам-приглашениям (Deep Linking)**:
  * При переходе по ссылке-приглашению группы (например, `/start <group_id>`), бот автоматически привязывает студента к этой группе и сразу запрашивает ФИО, исключая этап ручного выбора группы.
* **Переход в другую группу**:
  * Если зарегистрированный студент переходит по ссылке-приглашению другой группы, бот предлагает ввести ФИО для подтверждения перевода, сбрасывает прошлую сессию тестов и регистрирует в новой группе.
* **Изоляция контента**:
  * Кнопки «Предметы» и «Конспекты» показывают учебный материал **только** для выбранной группы.
  * Статистика тестов рассчитывается отдельно под каждую группу.
* **Смена группы вручную**:
  * Кнопка `🚪 Выйти из группы` позволяет сбросить текущую регистрацию и выбрать другую группу вручную.
* **Защита от удаления**:
  * Если преподаватель удаляет группу в админке, бот автоматически сбрасывает состояние привязанных к ней студентов при первом же их сообщении и просит зарегистрироваться в другой группе.

## 🛠 Установка и настройка

### 1. Установка зависимостей
Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```
*(В список добавлены библиотеки `pypdf` для чтения PDF и `python-dotenv` для конфигурации)*.

### 2. Настройка файла окружения (`.env`)
Создайте файл `.env` в корневом каталоге проекта на основе следующего шаблона:

```env
# Telegram Bot Token от @BotFather
BOT_TOKEN=ваш_токен_телеграм_бота

# Настройки ИИ (Groq API)
GROQ_API_KEY=ваш_ключ_groq_api
GROQ_MODEL=llama-3.3-70b-versatile

# Настройки бэкенда и БД
STUDYBOT_AI_DB=data/studybot_ai.db
FLASK_SECRET_KEY=произвольный_секретный_ключ_сессии

# Настройки почты (SMTP) для подтверждения регистрации
# (Для локального тестирования без почты коды будут выводиться в консоль Flask)
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=ваша_почта@gmail.com
SMTP_PASSWORD=ваш_пароль_приложений_google
```

## 🚀 Запуск проекта

### 1. Запуск панели управления (Flask)
Выполните команду в терминале:
```powershell
flask --app studybot_ai.admin run --port 5001 --debug
```
* Перейдите в браузере по адресу: [http://127.0.0.1:5001](http://127.0.0.1:5001).
* Зарегистрируйтесь (если SMTP не настроен, возьмите код подтверждения из вывода терминала).
* Создайте группу, выберите её, добавьте предметы и загрузите учебный PDF-файл для генерации теста.

### 2. Запуск Telegram-бота
Выполните команду в другом окне терминала:
```powershell
python -m studybot_ai.bot
```
* Запустите бота в Telegram, выберите созданную в админке группу и пройдите регистрацию.
